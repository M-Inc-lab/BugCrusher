## Detailed Findings

### 1. Apollo Tracing Enabled (MEDIUM / P5)

**Endpoint:** `https://id.atlassian.com/gateway/api/graphql`

**PoC:**
```bash
curl -X POST "https://id.atlassian.com/gateway/api/graphql" \
  -H "Content-Type: application/json" \
  -d '{"query":"{ __typename }"}'
```

**Response contains:**
```json
{
  "extensions": {
    "tracing": {
      "version": 1,
      "startTime": "...",
      "endTime": "...",
      "duration": ...,
      "parsing": {...},
      "validation": {...},
      "execution": {...}
    }
  }
}
```

**Impact:** Apollo tracing exposes resolver-level performance metrics, internal architecture, and query execution timing. This is information disclosure only — no direct exploit path without authentication.

**CVSS:** 5.3 (MEDIUM)
**Vector:** Information Disclosure — Apollo Tracing Enabled

### 2. GraphQL Introspection Enabled (INFO / P5)

**Endpoint:** `https://id.atlassian.com/gateway/api/graphql`

**PoC:**
```bash
curl -X POST "https://id.atlassian.com/gateway/api/graphql" \
  -H "Content-Type: application/json" \
  -d '{"query":"{ __schema { queryType { name fields { name type { name kind } } } } }"}'
```

**Key Query Fields Discovered:**
- `glance_getVULNIssues` — Vulnerability tracking
- `avpanalytics_getDataSource`, `avpanalytics_getModel`, `avpanalytics_previewModelData` — Analytics/AI models
- `confluence_contentAISummaries`, `confluence_contentAISummariesByContentId` — Confluence AI
- `playbook_*` — Playbook operations
- `jsmAgentWorkspace_locations` — JSM workspace locations
- `jiraOpenBeta_*` — Beta Jira features
- `forYouFeed` — Personalised feed

**Impact:** Schema enumeration exposes internal product capabilities, AI features (AVP, Confluence AI, Rovo), and JSM/Playbook integrations. No sensitive data exposed without authentication.

**CVSS:** 0.0 (INFO)
**Vector:** GraphQL Introspection — 50+ query fields enumerated
