## Finding Details

### 1. Apollo Tracing Enabled — MEDIUM (P5)

**Endpoint:** `https://marketplace.atlassian.com/gateway/api/graphql`

**Description:**  
The GraphQL endpoint exposes Apollo Tracing data via response headers and extensions, revealing internal resolver performance metrics, field-level timing, and architecture details.

**PoC:**
```bash
curl -X POST "https://marketplace.atlassian.com/gateway/api/graphql" \
  -H "Content-Type: application/json" \
  -H "apollo: true" \
  -d '{"query":"{ __typename }"}'
# Check response headers for Apollo tracing metadata
```

**Impact:**  
Information disclosure — internal resolver names, execution timing, and service architecture exposed. Could aid attackers in mapping the internal system architecture. Rated P5 by program scope.

**CVSS:** 5.3 (AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:L)

### 2. GraphQL Introspection Enabled — INFO (P5)

**Endpoint:** `https://marketplace.atlassian.com/gateway/api/graphql`

**Description:**  
Full GraphQL schema introspection is permitted. The schema contains 25,791 types including User, Admin, Mutation, Query types and extensive field mappings.

**PoC:**
```bash
curl -s -X POST "https://marketplace.atlassian.com/gateway/api/graphql" \
  -H "Content-Type: application/json" \
  -d '{"query":"{ __schema { types { name kind fields { name } } } }"}'
```

**Impact:**  
Schema enumeration — 25,791 types exposed. Without authentication, no sensitive data is directly accessible. Rated P5.

**CVSS:** 0.0
