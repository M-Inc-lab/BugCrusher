### [MEDIUM] Apollo Tracing Enabled — Internal Architecture Disclosure

| Field | Value |
|-------|-------|
| **Endpoint** | `https://id.atlassian.com/gateway/api/graphql` |
| **CVSS** | 5.3 |
| **Severity** | MEDIUM |
| **Est. Bounty** | $325 (P3) |

**Description:**
Apollo Tracing is enabled on the Atlassian Identity GraphQL API. This exposes internal resolver performance metrics including field-level execution times, which can reveal:

- Internal service architecture and data flow
- Field access patterns that may correlate with business logic
- Potential timing attacks on resolver performance
- Internal type relationships and dependencies

**PoC:**
```bash
curl -X POST https://id.atlassian.com/gateway/api/graphql \
  -H "Content-Type: application/json" \
  -d '{"query":"{ __typename }"}'
# Response includes Apollo Tracing headers
```

**Impact:**
Information disclosure of internal GraphQL resolver architecture. While not directly exploitable, this aids attackers in understanding the system internals for more targeted attacks.

**Remediation:**
Disable Apollo Tracing in production GraphQL deployments.
