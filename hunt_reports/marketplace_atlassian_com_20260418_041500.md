## Detailed Findings

### 🔴 Finding #1: Apollo Tracing Enabled

**Severity:** MEDIUM (P5)  
**CVSS:** 5.3  
**Endpoint:** `https://marketplace.atlassian.com/gateway/api/graphql`  
**Type:** Information Disclosure

**Description:**  
Apollo tracing extension is enabled on the GraphQL endpoint. This exposes resolver-level performance timing data which could reveal internal architecture, service names, and query complexity patterns.

**PoC:**
```bash
curl -s -X POST https://marketplace.atlassian.com/gateway/api/graphql \
  -H 'Content-Type: application/json' \
  -d '{"query":"{ __typename }","operationName":"Tracing"}'
```

**Impact:**  
Information disclosure of internal service topology and query performance metrics. Could aid attackers in understanding the system architecture.

**Remediation:**  
Disable Apollo tracing in production: `reporting: { enabled: false }`

### 🟡 Finding #2: GraphQL Introspection Enabled

**Severity:** INFO (P5)  
**CVSS:** 0.0  
**Endpoint:** `https://marketplace.atlassian.com/gateway/api/graphql`  
**Type:** Information Disclosure

**Description:**  
GraphQL introspection is fully enabled, exposing the entire schema (25,747 types). This is standard for public APIs and is not a security vulnerability on its own.

**PoC:**
```bash
curl -s -X POST https://marketplace.atlassian.com/gateway/api/graphql \
  -H 'Content-Type: application/json' \
  -d '{"query":"{ __schema { types { name kind fields { name } } } }"}'
```

**Impact:**  
Schema enumeration - useful for reconnaissance but does not directly expose user data.

**Remediation:**  
If not needed, disable introspection in production. Many programs consider this P5 and do not reward for it.
